Telecom Customer Churn Prediction & Revenue Forecasting
Project Overview
This project is about analyzing telecom customer data to:
- Predict which customers are likely to churn
- Understand the main reasons behind churn
- Suggest business strategies to reduce churn
- Predict Monthly Charges using regression models
Models Used
Classification (Churn Prediction)
- Linear Regression (baseline)
- Decision Tree
- Random Forest
- SVM
- KNN
Regression (MonthlyCharges Prediction)
- Linear Regression
- Ridge, Lasso, ElasticNet
- Decision Tree Regressor
- Random Forest Regressor
- SVR
Key Findings
- Random Forest gave the best performance for churn prediction
- Important factors affecting churn:
- Tenure (how long customer stays)
- Contract type
- Monthly charges
- Customers with month-to-month contracts and high charges are more likely to churn
Business Insights
- Focus on customers with high churn probability
- Offer discounts or long-term plans
- Improve services for high-risk segments
- Model-based targeting gives better results than random targeting
